# 时间线资源

本目录随子主题部署，运行时不依赖工作区外部素材库。

- `minecart.glb` / `end_chest.glb`：矿车与末影箱模型。
- `ender-chest.png`：模型不可用时的箱子替代图。
- `Minecraft.ttf`：像素字体。
- `rider.json`：主线与起源支线的皮肤配置，保留你的现有设置。
- `skins/`：64×64 皮肤及配置说明。
- `textures/`：地形、火把、工作台与书页所需纹理。
- `history/`：15 张正式历史图片，`manifest.json` 保存事件关联和来源。
- `audio/`：保留的三份音效；当前时间线未播放，供之后使用。

Three.js 及匹配加载器统一位于 `../../js/vendor/three-r160/`，保留许可证。旧版库、废弃模型和重复图片已移出子主题归档。

上传时保持这些路径不变。测试脚本位于主题 `tests/`，无需部署；工作区 `_archive/`、`minecraft-asset/`、`local-real-timeline.php` 也无需上传。
