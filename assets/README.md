# 资源目录

主题运行资源优先按来源整理，再在来源目录内按类型划分：

- `minecraft/`：来自 Minecraft 的资源。
  - `audio/`：游戏音效。
  - `texture/block/`：方块、铁轨、火把和工作台纹理。
  - `texture/particle/`：粒子和方块破坏纹理。
  - `texture/item/`：工具等物品纹理。
  - `texture/gui/`：书本等界面纹理。
  - `model/`：矿车与末影箱模型。
  - `font/`：Minecraft 像素字体。
- `skin/`：玩家皮肤以及 `rider.json` 乘客配置，可供不同页面复用。
- `images/`：不属于 Minecraft 原生素材或玩家皮肤的普通界面图片。
